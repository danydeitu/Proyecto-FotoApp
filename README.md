# 🚀 Proyecto Integrador: Procesamiento de Imágenes y Machine Learning

El proyecto se divide en dos módulos principales: un sistema de procesamiento y adaptación de imágenes (`fotoapp.py`) y un modelo predictivo de regresión lineal múltiple aplicado a costos de salud.

---

## 📂 Estructura del Repositorio

```text
├── imagenes/                  # Carpeta de imágenes de prueba (locales)
├── fotoapp.py                 # Módulo principal con las funciones de imagen
├── fotoapp_testdev.ipynb      # Notebook de pruebas (Parte 1: Imágenes)
├── parte2_regresion.ipynb     # Notebook de análisis y modelo (Parte 2: ML)
├── insurance.csv              # Dataset de seguros médicos (descarga automática)
├── requirements.txt           # Librerías y dependencias del proyecto
└── README.md                  # Documentación oficial del proyecto
